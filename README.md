# Kunal Kharat — Personal Portfolio

A responsive personal portfolio website built with vanilla HTML, CSS, and JavaScript.

The portfolio showcases my education, experience, technical skills, internships, projects, achievements, and contact information through a modern dark-themed interface with glassmorphism and cyan/purple gradient accents.

## 🎨 Design

The website follows a dark visual system built around:

- Deep navy/black backgrounds
- Cyan accent #00d4ff
- Purple accent #a855f7
- Glassmorphism surfaces
- Subtle borders
- Soft ambient glows
- Gradient typography
- Monospace typography for technical elements

The primary design tokens are centralized in CSS variables for easier maintenance and consistency.


---


## ⚡ Animations & Interactions

The website uses JavaScript to enhance the user experience.

### Typing Animation

The hero section dynamically displays role/tagline text.

### Animated Counters

Statistics animate from zero to their target values when initialized.

### Scroll Reveal

Elements using the reveal class animate into view as they enter the viewport.

### Skill Bars

Skill proficiency bars animate when their corresponding section becomes visible.

### Particle Background

A canvas-based particle system creates a subtle animated background effect.

### Mobile Navigation

A responsive hamburger menu provides navigation on smaller screens with keyboard-accessibility handling.

## 🚀 Getting Started

Since this project uses vanilla HTML, CSS, and JavaScript, no build tool or framework is required.

1. Clone the repository

git clone https://github.com/KunalKharat77/portfolio-website.git

2. Open the project

cd portfolio-website

3. Run the website

Open index.html directly in your browser.

For development, you can also use the Live Server extension in VS Code.
